# ✅ Todo App
A simple Todo web application to add, manage, and remove daily tasks efficiently.


## ✨ Features
- Add and delete tasks
- Simple task management
- Clean and minimal UI
- Responsive design


## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript  


## 🌐 Live Demo
- **Netlify:** https://todobymonitor.netlify.app/  
- **Vercel:** https://todobymonitor.vercel.app/  


## 🚀 How to Run Locally
```bash
git clone https://github.com/anilmonitor/todo.git
cd todo
```
Open index.html in your browser.
